# BetterDiscord Dual Theme

Allows you to select a light theme and dark theme, which will automatically be switched between when the system theme changes.

Useful if you have your system set to toggle between light and dark on a timer.

# Install

Download [the plugin file](https://github.com/MoshiKoi/BetterDiscordDualTheme/blob/deploy/dist/DualTheme.plugin.js) and copy it to your plugins directory.

# Build

Install dependencies and run the build script.
The transpiled plugin will be written to the `dist` directory.

```sh
pnpm install
pnpm run build
```
